## 1. توليد البيانات

### 1.1 الإشارة الصوتية
```python
def generate_test_signal(duration=0.01, sample_rate=192000, frequency=1000):
    """
    توليد إشارة اختبار
    
    Parameters:
    - type: 'sine' | 'white_noise' | 'speech-like'
    - frequency: 500-4000 Hz (نطاق الصوت البشري)
    - amplitude: normalized [-1, 1]
    - window: Hanning (لتقليل spectral leakage)
    """
    t = np.linspace(0, duration, int(sample_rate * duration), endpoint=False)
    signal = np.sin(2 * np.pi * frequency * t)
    window = np.hanning(len(signal))
    return signal * window
```

### 1.2 خصائص الإشارة
| المعيار | القيمة |
|---------|--------|
| التردد | 1 kHz (أساسي) |
| الترددات الاختبارية | 500, 1000, 2000, 4000 Hz |
| السعة | Normalized (peak = 1.0) |
| النافذة | Hanning window |
| المدة | 10 ms (نبضة) |

## 2. نموذج الضجيج

### 2.1 نوع الضجيج
```python
def add_noise(signal, snr_db=20):
    """
    إضافة ضجيج Gaussian أبيض
    
    SNR = 10 * log10(signal_power / noise_power)
    """
    signal_power = np.mean(signal ** 2)
    noise_power = signal_power / (10 ** (snr_db / 10))
    noise = np.random.randn(*signal.shape) * np.sqrt(noise_power)
    return signal + noise
```

```python
def calculate_arrival_times(source_pos, mic_positions, speed_of_sound=343.0):
    distances = np.linalg.norm(mic_positions - source_pos, axis=1)
    arrival_times = distances / speed_of_sound
    return arrival_times
```
